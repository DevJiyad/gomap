# Go Port Scanner

Fast, single-file TCP port scanner in Go.

`Made by dev/jiyad`

## Features
- Scans all 65,535 TCP ports concurrently
- Detects FTP, SSH, HTTP, and HTTPS
- Zero dependencies

## Usage
1. Set `target` in `main.go`
2. Run:
```bash
go run main.go
```
